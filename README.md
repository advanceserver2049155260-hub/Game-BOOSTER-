# Game Booster Pro

Android Game Booster starter project with a premium dark/neon UI.

## No Android Studio needed

You can build the APK with GitHub Actions from a phone.

### Mobile steps

1. Create a GitHub repository.
2. Upload all files/folders from this project ZIP.
3. Open **Actions** in the repository.
4. Select **Build Game Booster APK** and tap **Run workflow**.
5. After it finishes, open the workflow run and download **GameBoosterPro-debug** from Artifacts.

### Important

The RAM optimizer is best-effort because Android controls which background processes third-party apps may stop. It does not modify game files, inject memory, alter packets, use macros, or bypass anti-cheat.

The project is intentionally non-invasive. FPS monitoring and some performance controls depend on Android/device APIs.
